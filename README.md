# Data Generator

A synthetic stereo vision dataset generator for cylindrical landmark environments.

This project generates randomized 3D scenes containing cylindrical landmarks, simulates stereo camera observations, renders synthetic RGB images with realistic backgrounds, and produces compact vision matrices suitable for perception, localization, mapping, and machine learning experiments.

The generated dataset contains:

- Stereo image pairs
- Camera poses and calibration parameters
- Cylindrical landmark ground truth
- Polar occupancy-based vision representations

---

## Motivation

Many robotics and computer vision applications require large amounts of labeled training data. Collecting and annotating real-world datasets is expensive and time-consuming.

This project generates synthetic stereo observations of cylindrical landmarks while maintaining full access to ground truth geometry, camera poses, and landmark properties.

The generated data can be used for:

- Stereo vision research
- Robot localization
- Landmark-based navigation
- Feature matching
- Machine learning
- Synthetic data augmentation

---

## Dataset Generation Pipeline

For each scene:

1. Generate a random set of non-overlapping cylinders.
2. Sample a valid stereo camera pair.
3. Compute visible landmarks for each camera.
4. Project cylinders into image space.
5. Render synthetic RGB images using random backgrounds.
6. Build compact vision matrices.
7. Export images, camera parameters, and annotations.

---

## Scene Representation

Each cylinder is represented as:

```python
(x, y, z, radius, height)
```

Example:

```python
(3.2, -1.5, 0.0, 0.4, 50.0)
```

Cylinder placement is constrained such that no cylinders overlap in the XY plane.

---

## Camera Model

The project uses a pinhole camera model.

Each camera contains:

- Position
- Viewing direction
- Right vector
- Up vector
- Horizontal field of view

A stereo pair is generated by:

- Sampling a random baseline
- Positioning two cameras around the scene
- Orienting both cameras toward the landmark cluster
- Adding configurable angular jitter

---

## Projection Model

Visible cylinders are projected into image space as rectangular bounding regions.

Each projection stores:

```python
(idx, u_min, u_max, v_min, v_max, depth)
```

where:

- `idx` = cylinder index
- `u_min`, `u_max` = horizontal image coordinates
- `v_min`, `v_max` = vertical image coordinates
- `depth` = radial distance from the camera in the XY plane

Only cylinders inside the camera field of view are included.

---

## Vision Matrix

A compact polar representation is generated for each camera.

The field of view is discretized into angular bins.

Each bin stores:

| Channel | Description |
|----------|-------------|
| 0 | Occupancy |
| 1 | Cylinder radius |
| 2 | Radial distance |
| 3 | Cylinder ID |

Shape:

```python
(num_bins, 4)
```

Example:

```python
vision_matrix.shape
# (128, 4)
```

If multiple cylinders fall into the same angular bin, only the nearest cylinder is retained.

This representation can be interpreted as a simplified landmark sensor model similar to a polar occupancy map.

---

## Rendering

Synthetic RGB images are generated by:

- Loading a random background image
- Projecting visible cylinders
- Rendering cylinders as colored rectangular regions
- Performing simple depth ordering

Background images are loaded from:

```text
backgrounds/
```

## Generated Dataset Format

```text
dataset/
├── scene_000/
│   ├── images/
│   │   ├── pair_000_cam1.png
│   │   ├── pair_000_cam2.png

└── ...
```

---

## labels.json

Each scene contains:

```json
{
  "scene_id": 0,
  "cylinders": [...],
  "pairs": [...]
}
```

Each stereo pair contains:

- Camera images
- Vision matrices
- Camera intrinsics
- Camera extrinsics

Example:

```json
{
  "image1": "images/pair_000_cam1.png",
  "image2": "images/pair_000_cam2.png",
  "vision1": [...],
  "vision2": [...],
  "camera1": {...},
  "camera2": {...}
}
```

## Installation

Clone the repository:

```bash
git clone https://github.com/jo6815en/data_generator.git
cd data_generator
```

Install dependencies:

```bash
pip install numpy matplotlib pillow imageio jupyter
```

## Running the Generator

Open the notebook:

```bash
jupyter notebook parallel_generator.ipynb
```

Run all cells to generate a dataset.

Generated data will be saved in:

```text
dataset/
```
